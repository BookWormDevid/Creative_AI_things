## Структура

```text
LR0N/
├── Котов_Дэвид_Арсенович_Вариант_27_ЛР_N.docx   отчёт
├── Котов_Дэвид_Арсенович_Вариант_27_ЛР_N.pdf    отчёт в pdf
├── README.md          итоговые результаты и материалы
├── assignment/        методические указания и выданные материалы
├── src/               скрипты или ноутбук с кодом и результатами
├── artifacts/         результаты и контрольные суммы
└── reports/           сведения о среде, паспорт, журнал, сравнения
```

`N` — номер работы. Исходник отчёта — DOCX; PDF экспортируется вручную.

**Правила для всех работ:**

1. Все параметры эксперимента — в одном конфиге.
2. Рядом с каждым результатом — `manifest.json`: модель, полная ревизия, входные данные, seed, параметры, устройство, dtype, версии библиотек и SHA-256. Неприменимые поля отмечаются явно.
3. Ревизия модели фиксируется всегда: имя без ревизии указывает на подвижный снимок.
4. Веса моделей и виртуальное окружение не коммитятся. Версии среды и зависимостей фиксируются в материалах работы.
5. В документах, командах и журналах используются относительные пути.

## Инструменты

ЛР №1 — локальный Python и Engee; ЛР №2 — Python; ЛР №3 и №4 — Engee.
Версии среды указаны в материалах каждой работы.
