| Сцена | 5 «шахматная структура»: lo=0,15, hi=0,85, шум 0,02, checker=8; 128×128 |
| Воздействие | 3: уменьшение в 4 раза и возврат к исходному размеру; сравнение с уменьшением в 2 раза |
| Серия seed | 101–105, n=5 |
| Допуск | изменение метрики >5 % или средний PSNR <30 дБ; записан до запуска |
| Среда | Engee 26.10.2-H1, Julia 1.12.6 |

## Результаты

| Метрика | Δ, % | \|Δ\| > 2s | Практически важно |
| --- | ---: | :---: | :---: |
| Среднее | −0,111 | да | нет |
| Контраст | −9,864 | да | **да** |
| Энтропия | −8,386 | да | **да** |
| PSNR ×4 | 31,520 дБ | — | в допуске |
| PSNR ×2 | 34,256 дБ | — | в допуске |

- SHA-256 яркости при seed 101 воспроизведена: `2296bfdf7d29b6eb…`.
- Демонстрационная серия совпала с методическими указаниями: PSNR 34,594244830067446 дБ.
- Уменьшение ×4 даёт меньший PSNR для каждого seed; оба уменьшения превышают допуск 5 % по контрасту и энтропии.
- Для ×4 вывод о практической важности сохраняется при порогах 0,5–5 %; при 10 % практически важных изменений нет.

Правило 2s — учебный критерий, а не формальный статистический тест. Метрики рассчитаны по Float64; PNG служат 8-битными иллюстрациями.
