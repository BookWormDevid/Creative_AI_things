## Результат

Протокол воспроизводимости: `true, true, false, true`. При n=5 по учебному правилу `|Δ| > 2s_base` обнаружены изменения контраста, граничной энергии и энтропии; изменение средней яркости не обнаружено. Учебный критерий не является формальным статистическим тестом.

В Git отдельно зафиксирован протокол до новых запусков. Предыдущие материалы были доступны до очистки, поэтому это воспроизведение с новой фиксацией протокола, а не слепая первоначальная регистрация.
