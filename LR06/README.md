## Результаты

| Метрика | A, 512 | B, 768 | Δ/A | \|Δ\|/s | >2s | По допуску |
| --- | ---: | ---: | ---: | ---: | :---: | --- |
| CLIP | 27,6343 | 28,0588 | +1,536 % (Δ=+0,425) | 0,399 | нет | нейтрально |
| Энергия границ | 0,0353 | 0,0305 | −13,528 % | 0,388 | нет | ухудшение |
| Контраст | 0,1345 | 0,1077 | −19,964 % | 1,351 | нет | ухудшение |
| Время, с | 0,3070 | 0,6593 | +114,746 % | 11,515 | да | ухудшение |

- Время выросло в **2,147 раза**, практически важного выигрыша CLIP нет. Контраст снизился для каждого seed.
- На одном масштабе энергия границ в допуске: −1,085 % при 512, +3,789 % при 768; исходная разность во многом связана с масштабом.
- Для энергии границ и контраста допуск и 2s дают разные ответы. При удвоенном допуске эти метрики нейтральны; время остаётся вне допуска.
- Радужная фактура главная на всех кадрах, металл узнаётся неоднозначно. Композиции меняются; новый класс видимых разрывов только у 768 не установлен.
- Гипотеза подтвердилась по CLIP, энергии границ и времени, не подтвердилась по контрасту. Рост размера не доказал улучшения качества.
- Повтор seed 101 совпал в обоих режимах. Демонстрационные выводы воспроизведены; guidance=1 совпал с 0, при 3 CFG включён. Новый сеанс не проверялся.

«Ухудшение» границ и контраста означает отклонение от базового вида, а не оценку эстетики. Все 23 контрольные суммы и десять манифестов проверены; границы и контраст независимо пересчитаны по PNG.
