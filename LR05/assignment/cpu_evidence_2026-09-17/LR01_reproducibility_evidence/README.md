# ЛР №1 — воспроизводимый запуск SD Turbo

Фактический проверочный запуск демонстрационного примера из методических указаний.

## Запуск

```bash
export HF_HOME="$PWD/cache/huggingface"
.venv/bin/python src/run_reproducibility.py 2>&1 | tee reports/run_console.log
```

Параметры эксперимента находятся в `configs/run_config.json`. Два результата
сохраняются раздельно в `artifacts/run_001` и `artifacts/run_002`.

## Критерий воспроизводимости

Файл `reports/sha256_comparison.json` должен содержать
`"exact_sha256_match": true`. Это подтверждает побитовое совпадение двух запусков
внутри одной зафиксированной среды, но не обещает совпадение между разными
устройствами, версиями PyTorch или платформами.

Каталог `.venv` и кэш весов модели в итоговый архив не включаются.
