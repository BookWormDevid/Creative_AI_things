## Повторение из корня репозитория

Требуется Python ≥ 3.10. Сторонние пакеты для расчётов и сборки DOCX не нужны.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r LR01\requirements.txt
.\.venv\Scripts\python.exe LR01\src\run_lab01.py --out LR01\artifacts\repeat01
```

Выходной каталог должен быть новым: программа отказывается перезаписывать предыдущие результаты. Скрипты преподавателя сохранены без изменения; `run_lab01.py` запускает их и добавляет проверку отдельных seed, парную стандартную ошибку и описательную проверку пространственной равномерности.

Для одного основного опыта:

```powershell
.\.venv\Scripts\python.exe LR01\src\lab01_experiment.py --variant 27 --seed 101 --n 5 --out LR01\artifacts\repeat_single
```

Отчёт оформляется в DOCX, PDF экспортируется вручную. Скрипты автоматической сборки и экспорта отчёта удалены; ручное оформление сохраняется. Паспорт хранится в Markdown и включает части А и Б.

## Результат

Протокол воспроизводимости: `true, true, false, true`. При n=5 по учебному правилу `|Δ| > 2s_base` обнаружены изменения контраста, граничной энергии и энтропии; изменение средней яркости не обнаружено. Учебный критерий не является формальным статистическим тестом.

В Git отдельно зафиксирован протокол до новых запусков. Предыдущие материалы были доступны до очистки, поэтому это воспроизведение с новой фиксацией протокола, а не слепая первоначальная регистрация.
