# Паспорт набора данных · ЛР 2 · вариант 27

## 1. Motivation

Набор создан для учебной проверки лицензий и происхождения материалов электронного каталога фотоархива. Цель — разобрать NoDerivatives при публикации оригиналов и принять решение по каждому предупреждению. Это не готовый каталог для публичного выпуска.

## 2. Composition

12 синтетических записей: 4 image, 4 audio, 4 text. Название сценария не меняет смешанный состав выданного генератора. Медиафайлов нет. Лицензии: CC0-1.0 — 7, CC-BY-ND-4.0 — 3, MIT — 1, Apache-2.0 — 1. Персональных данных по условным меткам — 0. У пяти записей учебный каталог лицензий требует атрибуции; для MIT и Apache нужно также сохранить применимые уведомления и текст лицензии, а не ограничиться именем автора.

Поля: id, filename, media_type, source, date_acquired, license, rights_holder, personal_data, consent, sha256. Суммы получены из строк variant27-itemNN. item09 намеренно имеет сумму item06. Это не хеши отсутствующих медиафайлов.

## 3. Collection Process

Записи созданы lab02_make_variant.py для N=27; внутренний seed — 1027. Скачивания материалов не было. example.org, Автор-NN, лицензии и даты — учебные значения. Диапазон условных дат: 04.01.2026–08.08.2026; это не даты реального сбора. Источник методики — LR02/assignment/. Подтверждений прав и реальных согласий нет и не требуется для вымышленных записей; их наличие в реальном архиве пришлось бы проверять отдельно.

## 4. Preprocessing/cleaning/labeling

Исходный LR02/artifacts/v27/manifest.csv сохранён. Аудит: 0 ошибок, 1 предупреждение R9 (item09). Решение: карантин item09 из-за совпадения суммы с item06 при разных лицензиях и авторах. В списке кандидатов 11 строк, в карантине — одна; оба списка сохранены в LR02/reports/report_data.json. Дедупликация касается записей, а не медиа: реальных файлов нет. Ничего не исправлено по догадке. Повторный аудит кандидатов: 0 ошибок, 0 предупреждений; статус прав остаётся неподтверждённым.

## 5. Uses

Сценарий: некоммерческая публикация без производных; передача производных на тех же условиях не допускается. item07, item08, item11 с ND остаются учебными кандидатами при сохранении оригиналов, атрибуции и лицензионной ссылки. Условие ND не запрещает такую публикацию автоматически. Если нужны кадрирование, ретушь или иная адаптация, выбрать подтверждённый CC0/CC-BY либо получить отдельное разрешение. Не применять набор для обучения, оценки качества изображений или реального публичного фотоархива.

## 6. Distribution

Распространяются учебные метаданные и результаты проверки в репозитории; после публикации изменений их можно скачать стандартным ZIP-архивом GitHub. Это не публикация 12 медиаобъектов. Сведения об авторах пяти записей — в исходном манифесте; item09 помечен карантином в решениях аудита. Условные лицензии объектов не являются лицензией на методические материалы. Собственный код — MIT; лицензия исходных скриптов преподавателя не указана. Авторские права на результат генератора ЛР 1 из этого аудита не выводятся.

## 7. Maintenance

Сопровождение учебного набора: Котов Дэвид Арсенович. Перед изменением сценария — новый аудит и пересмотр ND. При обращении через issue репозитория зафиксировать id, основание и дату, снять спорную запись с публикации до проверки, сохранить решение в журнале и выпустить новую версию манифеста с SHA-256. Перед реальным выпуском проверить первоисточники лицензий, полномочия правообладателя, уведомления и права изображённых лиц. Учебный аудит — не юридическая консультация.
