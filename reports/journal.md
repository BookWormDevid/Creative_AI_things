# Журнал лабораторной работы № 1 — вариант 27

## Предварительная регистрация гипотезы (до запусков)

Контекст: «зернистая плёнка (постобработка)». Исследуемый фактор: изменение только шага решётки cell с 2 на 4 пикселя при параметрах size=96, octaves=2, persistence=0.70, quantize=8, interp=smooth. Базовый seed S=101; основная серия n=5 (101–105); протокол воспроизводимости 101, 101, 1101, 101.

**Порог до эксперимента:** существенное изменение отдельной метрики обнаружено при |mean_factor − mean_base| > 2·s_base, где s_base — выборочное стандартное отклонение метрики по разным seed (делитель n−1). При n=5 данный критерий не является формальным статистическим тестом.

**Гипотеза до эксперимента:** удвоение cell делает пространственные детали крупнее, поэтому средняя граничная энергия (среднее абсолютное различие соседних по горизонтали пикселей) должна снизиться; ожидается превышение учебного порога именно по этой метрике. Из-за усиления пространственного сглаживания ожидаются слабое уменьшение контраста и энтропии, а средняя яркость должна оставаться близкой к прежнему уровню. Укрупнение решётки сократит количество независимых узлов, вследствие чего могут возрасти колебания средних значений между seed. Проверить последнее по s_base и s_factor, затем в расширенных сериях n=20,50. Не считать общее изменение s равномерным для всех метрик заранее; проверка — наблюдательная.

**Связь с контекстом:** для имитации плёночного зерна ожидаемое снижение граничной энергии означает более крупное, менее мелкое зерно; равномерность оттенка по кадру и стабильность по seed требуется обсуждать отдельно. Визуальное впечатление не подменяет метрическую проверку.

Гипотеза фиксируется в этой записи до основного вычислительного запуска. Ни гипотеза, ни численный порог не корректируются по полученным данным.
