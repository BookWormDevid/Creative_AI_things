# ЛР №4. Исследование операций обработки изображений в Engee

**Котов Дэвид Арсенович · вариант 27 · подготовлена к запуску**

[Журнал](reports/journal.md) · [скрипт Engee](artifacts/engee/LR04_27.ngscript) · [исходник Julia](src/LR04_variant27.jl)

В примере актуальная работа находится в

| Параметр | Значение |
| --- | --- |
| Сцена | 5 «низкий контраст»: диск 0,55, фон 0,35–0,50, шум 0,03; 128×128 |
| Операция | 3: фильтр Гаусса σ=3 |
| Серия | seed 101–105, n=5 |
| База | зашумлённая сцена без обработки |
| Эталон | та же сцена без шума, clean4(5) |
| Практический допуск | ΔPSNR ≥ +1 дБ — полезна; ≤ −1 дБ — вредна; иначе нейтральна |
| Учебный критерий | \|Δ\| > 2s отдельно от практической пользы |
| Статус | гипотеза записана до запуска; фактические результаты ещё не получены |

## План

1. Подключить две библиотеки, зафиксировать версии среды, Julia и Images.
2. Создать зашумлённую и чистую сцены; повторить SHA входа.
3. Сравнить базовый PSNR с оценкой −20·lgσₙ и применить фильтр.
4. Сохранить изображения; получить метрики по пяти seed и классификацию по допуску.
5. Выполнить проверки из примера: карты ошибки и границ, развёртка по шуму, соседние варианты, демо и неверный эталон.
6. По результатам заполнить журнал и паспорт, оформить DOCX по примеру. PDF экспортируется вручную.

## Как выполнить в Engee

1. Создать папку LR04 рядом с LR03 в своей рабочей области.
2. Загрузить в неё три файла из `LR04/artifacts/engee/`: `lab03_lib.jl`, `lab04_lib.jl`, `LR04_27.ngscript`.
3. Открыть скрипт в редакторе. В первой ячейке `W` указывает на папку LR04 рабочей области Котова Дэвида Арсеновича; при другом расположении заменить только этот путь. Версию Engee из заголовка записать в журнал.
4. Выполнить **13 ячеек по одной сверху вниз**. Значения VERSION и Images берутся из фактического вывода, а не из метаданных ngscript.
5. Сохранить результаты из Engee в `LR04/artifacts/engee/` репозитория: `v27_results.txt` и девять PNG. При необходимости снимки выполнения сохранить в `LR04/reports/figures/`.
