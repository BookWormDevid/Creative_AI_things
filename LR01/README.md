## Что требуется

Подготовить изолированную среду, зафиксировать условия эксперимента и проверить воспроизводимость по отпечаткам полных массивов пикселей. Использован учебный генератор процедурных текстур; обучаемой модели и весов нет.

## Вариант 27

27 = (5 − 1) × 6 + 3: контекст 5, фактор 3.

| Параметр | Значение |
| --- | --- |
| Контекст | зернистая плёнка (постобработка) |
| Изменяемый фактор | шаг решётки ×2: cell 2 → 4 |
| Параметры | размер 96×96, октав 2, затухание 0,70, quantize=8, interp=smooth |
| Базовый seed / число seed | 101 / 5 |
| Учебный критерий | \|Δ\| > 2s базы; зафиксирован до новых запусков |
| Среда | CPython 3.10.6, Windows 10 AMD64, zlib 1.2.12; сторонние пакеты не используются |
