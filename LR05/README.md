## Результаты

| Проверка | Результат |
| --- | --- |
| SHA-256 A / B | различны; полные значения — в манифестах и паспорте |
| Совпадение пикселей | нет |
| Максимум различия | 231 из 255 |
| PSNR A/B | **13,044457 дБ**, different |
| Повтор со свежим генератором CPU | SHA совпал |
| Готовые тензоры шума через latents | воспроизвели соответствующие A и B бит в бит |
| Один и тот же шум, разные устройства Generator | SHA изображений совпали |
| Общий генератор на два вызова | второе изображение отличается; PSNR 13,911180 дБ |
| Новый сеанс | не проверен |

- Гипотеза подтвердилась: одинаковый seed не уравнивает последовательности CPU и CUDA. Различие связано с начальным шумом; модель в обоих условиях работает на одной GPU.
- На обоих изображениях главная радужная блестящая фактура. Узнаваемость именно металла неоднозначна, особенно в B; соответствие брифу отмечено с оговоркой.
- Демонстрационный запуск воспроизводится внутри сеанса, но SHA отличается от данных методических указаний. Окружения различаются; вклад отдельных изменений не изолирован.
- Все 14 контрольных сумм основного опыта проверены. PSNR и максимум различия независимо пересчитаны по исходным PNG и совпали со сводкой.
